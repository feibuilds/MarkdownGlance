## Automated checks

Date: 2026-09-06. Product changes: `d0f3181`, plus release metadata updates.

- Python 3.14.7, Markdown 3.10.3, pymdown-extensions 11.0.2.

The product commit's [CI run](https://github.com/pandadolphin/MarkdownGlance/actions/runs/34012958592) passed before release preparation.

## Native checks

Portable Sublime Text 4200 / Python 3.8.12 on Linux under Xvfb, using the repository's `run-markdownglance` math scenario. All four phases passed: math enabled, light scheme, redacted diagnostics, and math disabled. Screenshots were visually inspected: formulas are legible in both themes, invalid input has an inline placeholder, and disabled math remains source.

Evidence: [math enabled](release-0.4.2/math-on.json), [light scheme](release-0.4.2/light-scheme.json), [diagnostics](release-0.4.2/diagnostics.json), [math disabled](release-0.4.2/math-off.json). Corresponding PNGs accompany the JSON files.

The [contract runner](release-0.4.2/st4200-contract.json) passed. The [benchmark](release-0.4.2/st4200-benchmark.json) completed 100 samples after 3 warmups over 102,445 bytes: p50 434.822 ms, p95 469.917 ms. These are measurements, not a performance regression verdict against a controlled baseline.

## Browser and limits

Headless system Chrome loaded a synthetic page generated by `standalone_html` through `file://`. Light and dark themes each produced one Mermaid SVG and two KaTeX formulas. Screenshots were visually inspected. Blocking HTTPS requests preserved diagram and formula source. [Results](release-0.4.2/results.json), [light](release-0.4.2/light.png), [dark](release-0.4.2/dark.png), and [check script](release-0.4.2/browser-check.py).

This browser check directly exercises the renderer, not the Sublime palette command. It does not certify the earlier manual fixture's relative-image and fragment navigation. The full manual matrix, including macOS/Windows native behavior and installation/coexistence scenarios, was not rerun for 0.4.2.
