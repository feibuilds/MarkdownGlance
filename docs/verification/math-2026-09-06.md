## Method

The app is the real Sublime Text window, not the test suite. A throwaway
package, [`probe.py`](math-2026-09-06/probe.py) (Python 3.8 host), runs a
state machine on the UI thread from `plugin_loaded`: it opens
[`math.md`](math-2026-09-06/math.md), runs `mdglance_open_side_by_side`,
and after each phase reads the live session through
`container.usecases.manager` and writes a JSON snapshot (image count,
placeholders, asset labels, the colour baked into each locator, the theme
the session saw, and the body HTML with data URIs redacted). It then waits
for a `go<N>` file. [`drive.sh`](math-2026-09-06/drive.sh) launches the
portable binary, waits for each `.done` marker, captures the window with
`import -window` after raising it with `wmctrl`, and releases the next
phase. Phase 5 is `exit`.

The window is found with `xdotool search --all --pid --name`; without
`--all` the conditions are OR-ed and the first run captured an unrelated
Sublime Text instance. Those shots were discarded and the run repeated.

## Phase evidence

**Phase 1, Mariana.** Generation 5, no pending assets, three `img`
elements and one inline `Unavailable` placeholder for `$\frac{a$`, which
carries the one-time caption `formula source is sent to latex.codecogs.com`.
Four `math:latex.codecogs.com:*` assets, all with colour `216,222,233`
(`#d8dee9`, the scheme's foreground); the display one alone carries
`\displaystyle`. `$5 and $6` is a sentence, `` `$x$` `` and the fence are
code. Shown sizes: `a^2 + b^2 = c^2` at 95 × 18 px, the integral at
100 × 46 px, halved from the fetched PNGs.

**Phase 2, Breakers.** The session's theme moved to `#fcfdfd` / `#333333`,
light. Generation 10, all four asset labels changed and every colour is
`51,51,51`; the document settled with no pending asset. The theme change
alone triggered the render, no edit.

**Phase 3.** `mdglance_copy_diagnostics` output contains `enable_math:
true` and none of `a^2`, `frac`, `int_0`, `alpha` or a codecogs URL.

**Phase 4.** `enable_math` set to `false` in memory. Generation 11, no
assets, no images, four `<code class="math">` elements: two inline with
their `$`, the display block as `<pre><code class="math">`, and the
invalid formula as `$\frac{a$`.

## Observations

- Inline formulas sit a little above the baseline, as ADR 0013 says they
  will; readable, not distracting. The 115 dpi body matches the 16 px text
  in both schemes, so `DPI` in `preview/assets/math.py` stays as it is.
- The inline caption for an invalid formula is long. It appears once per
  render, on the first formula that is not ready, so a document whose
  formulas all render never shows it.
- Nothing in the console log on stdout; plugin prints are not echoed there
  by this build, so the absence of a traceback rests on the phases all
  completing and `error.json` never being written.
- The first, discarded run resized and raised two Sublime Text windows
  belonging to the earlier manual session at `/tmp/mdglance-manual-a576p_jy`.
  Their content was not touched.
