MarkdownGlance previews Markdown inside Sublime Text. No browser needed,
and the colours follow your color scheme.

Open a Markdown file and press Ctrl+K, V (macOS: Cmd+K, V) for a preview
beside it, or Ctrl+Shift+V (Cmd+Shift+V) for a full-screen one. It updates
as you type. Ctrl+Shift+B (Cmd+Shift+B) opens the contents panel. Every
command is in the Command Palette under "MarkdownGlance:".

Mermaid diagrams and LaTeX math are off by default: turning either on sends
diagram or formula source to a rendering server. SVG images need resvg.

Settings: Preferences → Package Settings → MarkdownGlance
Key bindings, options and more: https://github.com/feibuilds/MarkdownGlance#readme
